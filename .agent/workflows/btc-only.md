# BTC-only 首阶段工作流

## 固定范围

- 只运行 `BTC-USD`，适配器和服务端都会拒绝其他市场。
- 首轮使用 `TRADING_MODE=paper`，账户权益默认 `10,000 USDC`。
- PAPER 账户权益可在页面人工调整，但只允许在网格停止、非恢复状态、无持仓且机器人/交易所均无挂单时执行；该变更按模拟入金/出金处理，策略周期和当日盈亏必须在新权益上重建零基线，禁止记为策略收益。
- 启动只允许选择命名策略：`区间平衡`、`顺势多头`、`顺势空头`，以及仅 PAPER 可用的大周期轮动、Grok 情绪增强轮动和海龟突破策略。
- 页面不提供边界、格数、每格数量、杠杆、区间外动作、方向敞口和趋势保护的启动编辑框，只显示服务端只读预览。
- 策略参数由最新价格、`ATR(1h)`、账户权益、现有仓位、市场精度和实际执行损耗生成：默认 `2x`、`10-40` 格、`6%-18%` 区间半宽；中性目标格距不得低于 `0.6%`，也不得低于手续费、滑点和点差预计往返损耗的 `3` 倍。做多目标保证金约占权益 `8%`，中性和做空约占 `4%`。
- `/api/strategy-preview` 用于预览；`/api/strategy-start` 只接受策略 ID、市场 ID 和必要的实盘确认字段，并在真正启动前重新生成全部参数，禁止信任浏览器提交的数值。
- 单边净持仓名义价值默认不超过权益 `15%`；减仓单强制 `reduceOnly`，达到上限只停止加仓，不强制平仓。
- 趋势保护默认开启，每 `5` 分钟读取 BTC 1h K 线：强上升暂停开空，强下降暂停开多，退出方向不受阻断。
- `区间平衡`的实际入场必须由已完成的 1D 与 4H K 线共同确认震荡，且 1H ATR 达到成本覆盖格距。PAPER 点击启动时准入未通过仍进入明确的`等待准入`运行状态，保持零挂单；每 5 分钟重新检查，满足后按最新运行参数自动挂出第一组被动限价单。准入不自动切换做多/做空，已有减仓单继续执行。已经准入后的周期分歧沿用现状，只有 1D/4H 同向且趋势强度均达门槛才撤销准入，避免短周期反复开关。LIVE 仍把准入失败作为启动阻断。
- 中性网格对加重现有库存方向的开仓单启用连续数量偏置：方向敞口达到上限的 `25%` 后开始分档缩量，接近上限时最低缩至原单量的 `25%`；减仓方向保持原数量并强制 `reduceOnly`，最终仍受权益 `15%` 硬上限约束。
- 静态策略不会自行从停止状态启动；必须在页面人工点击“启用策略”。PAPER 空闲实例的启动按钮不受只读预览 `ready` 状态锁死，允许在紧急停止或一次校验失败后再次点击并触发最新服务端校验；价格、参数、保证金和遗留状态失败仍拒绝启动。`区间平衡`是唯一允许以准入未通过进入`等待准入`的静态网格，条件满足后自动挂单。LIVE 启动按钮继续要求全部预览通过。选择静态策略或人工停止/撤单/平仓时必须关闭大周期自动轮动，避免稍后自动重启。
- PAPER 页面不得显示 Decibel API 钱包、Trading Account、目标网络、代理、目标模式或重启设置；这些连接设置只属于 `/live`。
- PAPER 最多允许 `6` 个独立模拟盘。所有实例共享同一 BTC 行情时钟以保证对照公平，但余额、仓位、挂单、成交、盈亏、执行成本、策略选择、统计周期和小时参数状态必须隔离。
- 实例卡片必须持续显示实际运行策略。运行时策略选择锁定为 `bot.config.strategyId`，停止后恢复该实例持久化的选择；任何刷新、SSE 更新或实例切换都不得回到策略列表第一项。
- 主模拟盘不可删除；其他实例只有在已停止、无恢复、无仓位且无挂单时可以删除。大周期自动轮动和 Grok 情绪增强轮动暂只允许主模拟盘，其他实例只运行静态中性/做多/做空策略。
- 每个 PAPER 实例的紧急停止只处理该实例，固定执行停止、撤单和平仓；完成后保留已选命名策略、立即刷新策略预览，并在实例空闲时恢复启动按钮。紧急停止不是策略准入或风险豁免，已无运行配置、仓位和挂单时停止/平仓按钮保持禁用属于正常状态。

## 启动和检查

1. 复制 `.env.example` 为 `.env`，保持 `TRADING_MODE=paper`、`BTC_ONLY=true` 和 `AUTO_REBALANCE=true`。
2. 运行 `npm ci`，再运行 `npm test`，确认测试全部通过。
3. 启动 `npm start` 或对应的模拟盘启动脚本，访问 `http://127.0.0.1:15000/paper`；配置了 Basic Auth 时使用 `.env` 中的管理员凭据。
4. 页面核对以下就绪项：PAPER 模式、BTC-only、有效 BTC 价格、行情数据源、参数风险状态、策略准入和有无遗留挂单或恢复状态。预览失败用于解释当前阻断原因，不负责永久禁用 PAPER 启动按钮。
5. 在“并行模拟盘”中选择或新建实例，再选择命名策略；核对只读预览后点击“启用模拟策略”，服务端会在启动前再次重算并执行最终校验。服务端拒绝时处理页面显示的最新原因后重试，不得把按钮可点击误解为风控已经通过。
6. 可切换到另一实例并启动不同静态策略；启动后核对每个实例卡片和监控区的实际策略、独立权益、挂单与仓位，主实例状态不得被其他实例覆盖。
7. 运行后核对监控条中的统计周期、方向敞口、趋势保护和 PAPER 执行损耗；敞口不得超过配置上限。

## 模拟成交口径

- 默认计入单边 `0.05%` 手续费、`2 bps` 滑点和 `1 bp` 点差。
- 每 `8` 小时结算一次 `0.01%` 资金费率；正费率下多头支付、空头收取。
- 默认成交确认延迟 `750ms`，并以 `35%` 概率先成交剩余量的 `50%`。
- 部分成交订单保留剩余数量；已成交数量单独生成 reduce-only 退出单，同价退出单合并且每个价位最多一个挂单。
- PAPER 使用公共现货模式时，趋势判断优先读取 Coinbase BTC-USD 已完成 K 线；4H 必须由 UTC 对齐且连续的四根 Coinbase 1H 聚合，缺小时或未收盘时不得形成 4H。失败后读取 Binance BTCUSDT；任何必需周期落到随机合成数据时必须阻断自动策略。
- 已运行网格中被方向敞口或趋势保护暂停的开仓单不会追价恢复：买单必须仍低于当前价、卖单必须仍高于当前价；已经穿过市场的旧档位继续暂停，等待重新成为被动限价或下一次调区间重建。`区间平衡`首次等待准入期间不预生成旧挂单；准入满足时直接按当前价格和最新小时参数生成第一组网格。等待期间价格离开旧区间不会触发停止，小时参数引擎只更新参数且保持零挂单，直到价格位于新区间且准入通过。

## 参数统计周期

- 每次成功启动、人工调区间、自动调区间或人工重置统计，自动创建新周期和参数版本。
- 新周期分别记录权益、已实现/未实现盈亏和执行成本基线，并重置成交数、完成格数、网格毛利、成交额及最近成交。
- 调区间不会删除完整操作流水；最近 `12` 个结束周期跟随运行快照保存，禁止把不同参数周期的收益直接相加比较。
- 调整 PAPER 权益前先封存旧周期的真实结果，调整后创建 `paper_equity_adjustment` 新周期；LIVE 模式必须拒绝同一接口和页面操作。

## 单边上涨处理

- `区间平衡`不会根据趋势信号自动切换方向；只有人工选择`大周期自动轮动`时可以自动切换。
- 明确的持续上涨行情选择`顺势多头`，避免中性网格在上升过程中不断新增空头；所有数值仍由服务端生成。
- 区间平衡已运行时，必须先停止、撤单并处理已有空头，再选择顺势多头；不得在旧仓位和旧挂单未处理时直接切换。

## PAPER 大周期自动策略

- 默认关闭，只能通过 PAPER 页选择`大周期自动轮动`并人工确认启用；LIVE 服务和实盘页面必须拒绝启用。
- 启用时先无前视回放最近 `12` 个小时决策，每个决策点只能读取当时已经完成的 1D、4H 和 1H K 线；历史已连续满足门槛时立即挂单，只满足末尾若干次时保留该连续次数。之后默认每 `60` 分钟读取一次，同一根已完成 1H 不得重复计数；三个周期必须连续 `12` 小时全票一致，才形成中性、做多或做空切换目标。
- 成功启动或切换后至少保持 `2880` 分钟。周期信号暂时不一致时保持当前策略，不平仓、不切换；震荡周期运行中性网格，只有剧烈波动安全信号允许暂停。
- 方向由可回测的确定性规则决定，不依赖 AI API Key；配置大模型时只补充解释。每次实际切换都按最新 BTC `ATR(1h)`、权益、仓位和市场精度重新生成区间、格数、每格数量、杠杆与保护参数。
- 自动动作前必须完成 BTC-only、网格数量、最小下单量、保证金和风险检查。检查必须在撤销旧网格前完成，避免先停止再发现新参数不可用。
- 切换方向固定执行撤单、平仓确认、账户清洁确认、重新启动；任一步未确认都不得挂新网格。“不适合网格”连续确认后执行撤单平仓并保持暂停。
- 数据不足、多周期不一致、恢复流程运行或空闲账户存在遗留仓位/挂单时保持现状并记录审计。
- 页面必须显示当前候选方向、确认次数、冷却、最近动作和阻断原因。服务端版本尚未重启时必须禁用策略启动，不得显示虚假的已生效状态。
- 降频门控只能减少自动动作，不能作为盈利保证。任何候选参数必须同时报告完整 3 年和不重叠年度窗口，出现亏损年度时不得描述为稳定盈利。

### Grok 情绪增强轮动（试验）

- 策略 ID 固定为 `sentiment_regime_v1`，仅主 PAPER 可用，要求 AI Provider 为 `xai` 且已配置 API Key；LIVE 和子模拟盘必须拒绝。
- 1D/4H/1H 确定性规则先产生候选方向，Grok 只能确认或阻断该方向。情绪不得独立创建方向，普通反向情绪不得反手；高可信反向重大事件只能形成风险暂停候选。
- 启动时不回放或伪造历史情绪。人工确认后立即搜索一次最近 24 小时 X 与网页，形成最多 `1/2` 候选；之后每 `15` 分钟重新搜索，至少 `3` 个独立引用来源、置信度 `0.65`、净情绪阈值 `±0.15` 并连续确认 `2` 次才执行。
- 每轮让 X Search（`45s` 超时）与 Web Search（`20s` 超时）只提取来源和事实，再用一次不带搜索工具的模型请求合并、评分（`20s` 超时）。原生 xAI 接口并行执行两个搜索；不保证并发额度的兼容代理按 Web→X 串行执行，避免代理队列互相阻塞。兼容代理全流程最坏超时为 `85s`。任一搜索渠道或合并失败时，本轮不得产生交易确认：运行中的策略保持不变，尚未入场的实例继续等待。
- 成功启动、切换或暂停后冷却 `360` 分钟。情绪冲突、来源不足、报告超过 `30` 分钟、xAI 不可用或搜索失败时保持现有策略；尚未运行则继续等待。
- 只接受 Grok Search 响应实际附带的引用；X 按账号、网页按站点计算独立来源。情绪快照、引用和决策写入审计，API Key 不得进入页面响应、日志或 Git。
- 当前没有可复现的历史 X/网页语料回测，该策略只能标记为 PAPER 前向试验，不能宣传为已验证收益策略。参数仍沿用 V3 的保守网格规模，不参考高杠杆账户样本。
- 当前部署自 2026-09-30 起暂停所有自动 AI 调用：`sentinelMinutes=0`、`marketMinutes=0`、`reportHour=-1`、`autopilotEnabled=false`。服务重启后必须继续读取这组本机设置；只有人工连接测试或人工情绪分析请求可以调用 Grok，恢复任何定时任务前必须由用户明确开启。
- 当前兼容代理的 `grok-4.6` 基础 Responses、Web Search 和 X Search 均已通过人工连通性测试，但两个搜索响应没有提供接口级 `citations`。模型正文中自行输出的 URL 不得替代响应引用；在代理能够返回可验证引用前，情绪报告必须因独立来源不足而保持无效，不得放宽来源门槛。

## 回测口径

- 1h 回测只能使用上一根已完成 K 线产生趋势信号和新网格，本小时高低价只撮合此前已经存在的订单，禁止使用本小时收盘价生成订单后再回填本小时成交。
- 大周期轮动回测使用 15m 数据，1H/4H/1D 特征只能由决策时刻之前已经完成的 15m K 线聚合；方向规则与 PAPER 必须共用同一分类器。
- 大周期轮动回测默认覆盖 1095 天并缓存 Coinbase 15m 数据；必须包含固定策略对照、零成本和加倍成本，以及置信度、连续确认和最短持有门槛敏感性。研究场景不得自动写回 PAPER/LIVE 配置。
- 参数优化固定使用前两年训练和其中的半年滚动窗口；最后 365 天在参数冻结前不得查看。冻结样本外净收益低于生产基线时，即使三年汇总或最大回撤更好，也不得替换 PAPER 默认策略。
- 低波动暂停、严格做空、提前退出、分模式格距和波动率仓位缩放必须作为显式候选参数回放；被样本外否决的规则可以保留在研究脚本中，但生产分类器和默认参数必须保持不变。
- 保持型 V3 研究候选在新方向未完成确认时继续运行现有策略，门槛不足只阻止切换，不触发平仓；剧烈波动、区间外止损和人工停止仍可进入空仓。V3 来自已查看过验证结果后的假设，只能进入新的 PAPER 前向观察，不能把既有三年回放重新称为样本外验证。
- PAPER 页面允许人工选择 `V3 保持型轮动（试验）`；它必须与标准轮动使用不同策略 ID，并把所选版本持久化到自动轮动状态。V3 执行固定使用做空强度 `0.40`、中性 ATR `0.70%`、中性最小格距 `0.8%` 和 `8%/4%/2%` 的做多/中性/做空目标保证金。实盘必须显示不可用。
- 稳健性研究固定只比较生产基线、V3、V3 禁止做空和 V3 做空单格数量再减半四个候选；禁止在看到验证结果后继续增加阈值组合。默认使用 5 年数据、18 个月训练加 6 个月验证的滚动窗口、`1x/2x/3x` 成本和单参数 `±20%` 扰动。
- 候选晋级必须同时满足全周期盈利、双倍成本盈利、最差半年亏损不超过初始权益 `1%`、滚动验证最差折亏损不超过 `1%`，且至少 `70%` 的滚动折盈利；被测试的参数扰动还必须全部盈利。没有候选全部通过时必须保留现有 PAPER 默认策略，禁止从失败候选中硬选收益最高者。
- 被保护拦截的订单进入暂停状态，条件解除后仅在仍为被动限价时恢复；输出暂停恢复次数、开仓/减仓成交数、成本前收益和执行成本总额。
- 中性网格历史回放必须复用运行时的震荡准入、成本格距、库存偏置和调参经济门槛；这些结构规则的默认门槛在走样本外验证前保持冻结，不得按单一回放窗口的最高收益回写。
- 顺势多头仓位倍率研究使用 `npm run backtest:long-scale`：固定区间生成、网格数量、成交规则、小时调参和趋势保护，只测试 `1x/2x/4x/6x/8x/10x` 单格数量。回放必须使用三年 Coinbase BTC-USD 15m、逐期真实资金费率、手续费、滑点、点差和期末强平，并同时报告全周期单次启动与三个独立年度启动窗口。Sharpe 使用 UTC 日度盯市权益收益年化；固定策略区间外停止后的空仓时间必须计入，禁止把单次启动结果解释为连续运行收益。
- PAPER `顺势多头` 当前采用上述研究中的 `6x` 单格仓位倍率：基础保证金预算 `8% × 6 = 48%`，方向敞口上限 `90%`，策略级启动保证金上限 `55%`；这些覆盖只允许用于 PAPER，LIVE 保持 `1x`、方向敞口 `15%` 和全局保证金上限 `35%`。
- `BACKTEST_GRID_SIZE_MULTIPLIER` 和 `BACKTEST_GRID_COUNT_MULTIPLIER` 用于规模/密度敏感性测试；`BACKTEST_TREND_SLOPE_THRESHOLD`、`BACKTEST_TREND_CONFIRM_BARS`、`BACKTEST_FLATTEN_ADVERSE_TREND`、`BACKTEST_REGIME_MODE_SWITCH` 仅用于实验，不代表运行时默认开启。
- 1h 数据无法可靠模拟 `750ms` 延迟和随机部分成交；回测收益只用于排除明显失败参数，不作为上线收益承诺。
- PAPER 做多海龟当前固定使用已完成日线的 20 日突破、10 日退出、20 日 Wilder ATR、`2N` 止损、`0.5N` 加仓、最多 4 单位、每单位 `1.5%` 风险和 `100%` 总名义金额上限；15m 只用于回放日内触发顺序。先用 `npm run fetch:funding` 获取公开逐期真实费率，历史模式覆盖率不足 `95%` 必须中止，禁止静默回退固定费率。报告必须分别列出手续费、滑点、点差、资金费率和期末强制平仓，并包含正常/双倍成本、固定费率压力对照、自然年和持有基准。该策略只允许 PAPER，参数调整不得扩大到 LIVE。

## 小时参数引擎

- 仅网格运行时检查，绝不自动启动网格。
- 默认每 `60` 分钟重算区间、格数、每格数量和杠杆；每次计算不等于每次撤单。
- 价格进入区间边缘 `20%` 且新区间变化达到 `10%`，或格数/每格数量变化达到 `20%`，先形成更新候选；中性网格还必须确认新参数的净网格能力改善足以覆盖一次执行摩擦准备金。边缘重心调整与降低单量/杠杆属于风险动作，但仍必须满足成本格距。成功后冷却 `240` 分钟。
- 参数更新保留当前策略方向和持仓，固定执行风险检查、确认撤销旧挂单、使用新参数重新挂单、审计记录和状态更新。
- 模拟盘默认开启，实盘默认关闭；页面和 `/api/state` 会显示最近时间、原因和冷却状态。

## 24 小时验收

手动启动后观察 24 小时，记录行情更新、初始挂单数量、成交后的反向补单、权益/仓位/成交同步、边缘调区间、撤单无重叠、停止撤单和平仓处理，以及重启后的状态恢复。验收关注执行稳定性和状态一致性，不以回测或 24 小时盈利作为上线条件。

## 实盘门槛

模拟盘稳定后再配置 Decibel API 钱包和 Trading Account，完成实盘预检、风险上限核对和小额验证。不要把私钥、`.env`、运行态快照或审计日志提交到 GitHub。

实盘准备统一在 `/live` 页面进行。模拟盘与实盘页面使用不同配色；当页面模式与服务实际模式不一致时，交易动作必须保持锁定，不能用页面切换代替服务模式切换。

页面状态也必须按模式隔离：PAPER bot 运行时，`/live` 只能显示“实盘服务未启动”，不得展示模拟盘的运行标记、账户权益、盈亏、仓位、挂单、网格参数或活动记录；反向场景同理。BTC 公共行情可以跨页面保留，供参数配置和图表查看。

页面实时状态优先使用 SSE；收到任意有效流消息即恢复“连接正常”。SSE 断开时使用 `/api/state` 轮询兜底，并明确显示“轮询正常”，不能在 API 和行情均正常时长期停留在“重连中”。页面执行模拟盘原地重启后必须关闭旧 EventSource 并显式建立新流；普通状态刷新不得把仍在活动的连接重置为“初始化”。

策略监控状态也按模式隔离，包括方向敞口、趋势守卫、执行损耗、当前统计周期和历史周期；不得从 PAPER 页面泄露到 LIVE 页面。
