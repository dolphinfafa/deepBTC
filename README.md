# GridPilot · Decibel 网格交易控制台

专为 **Decibel** 永续合约打造的本地网格交易控制台，支持模拟盘、实盘执行、命名策略自动参数、仓位恢复、风险控制和 Telegram 盈亏通知。

> 合约与杠杆交易存在本金损失风险。本项目不构成投资建议，建议先运行模拟盘，并根据自身资金规模设置实盘风控参数。

## 当前状态

- 版本：`1.0.0`
- 交易所：仅 Decibel
- 默认模式：`paper` 模拟盘
- Decibel SDK：锁定 `@decibeltrade/sdk 0.7.0`
- Node.js：20 或更高版本
- 支持：Windows、macOS

## 相关网站

- [Decibel 应用](https://app.decibel.trade/)：创建或管理 API 钱包、Trading Account，并核对订单与仓位。
- [Geomi](https://geomi.dev/)：申请 Decibel 行情与交易接口使用的 API Key。

## 核心能力

- 中性、做多、做空三种等差网格。
- 模拟撮合，可接入 Decibel 真实行情；没有 API Key 时先尝试公共现货行情，公共行情不可用才使用合成行情。
- PAPER 页面最多可同时保留 `6` 个独立模拟盘；各盘共享同一 BTC 行情时钟，但余额、仓位、挂单、成交、盈亏、执行成本、所选策略和小时参数状态完全隔离，可并行比较中性、做多和做空策略。
- 中性网格默认限制单边净敞口不超过权益 `15%`；减仓方向自动改为 `reduceOnly`，达到上限后撤销危险方向的开仓单。
- 趋势保护每 `5` 分钟读取 BTC 1h K 线；强上升时暂停新增空头，强下降时暂停新增多头，但始终允许减仓退出。
- PAPER 成交计入手续费、滑点、点差、8 小时资金费率、成交延迟和部分成交，页面提供独立成本拆分。
- 每次启动、调区间或人工重置都会创建新的统计周期，参数版本、盈亏基线和执行成本互不混算。
- 首阶段固定 `BTC-USD` 单市场；默认 PAPER 模式使用中性网格，实盘不会被自动开启。
- Decibel 实盘下单、撤单、杠杆设置、持仓同步、成交识别和订单对账。
- 启动时只选择命名策略，包括固定方向网格、大周期轮动、Grok 情绪增强轮动和海龟突破；边界、格数、每格数量、杠杆和保护参数均由服务端自动生成并只读预览。
- PAPER 可选择大周期自动轮动：用已完成的 1D、4H、1H K 线识别上涨、下跌或震荡周期；启用时先无前视回放最近 `12` 个小时决策，历史已经连续确认就立即运行对应网格，否则保留最近连续次数；实盘禁止使用。
- PAPER 另提供 `V3 保持型轮动（试验）`：弱下跌和低波动震荡不触发切换，继续保持已有策略；做空目标保证金约为权益 `2%`，用于前向模拟观察，不代表已通过上线验证。
- 主模拟盘另提供 `Grok 情绪增强轮动（试验）`：1D/4H/1H 规则先确定候选方向，xAI Grok Search 再用 X 和网页公开信息确认、阻断或触发风险暂停；情绪不能独立开仓或直接反手。
- 模拟盘就绪检查显示模式、BTC-only、价格源、保证金风险和遗留状态；静态策略只有人工点击“启用策略”才会运行。
- 启动快照、进程重启恢复、遗留订单接管和定期对账。
- 实盘启动前账户预检，覆盖连接、权益、API 钱包 Gas、挂单、持仓和风险状态。
- 服务端限制最大杠杆、保证金占比和维持保证金率；格数与名义金额上限可设为 `0`，交给动态风险计算。
- 持久化日内亏损与权益回撤锁；触发后自动撤单并尝试平仓。
- 初始挂单残缺时自动撤回并拒绝启动。
- 杠杆设置或遗留挂单撤销未确认时拒绝继续挂网格。
- 遗留仓位可选择重新建网格、只减仓回收或立即平仓。
- LIVE 页面可录入 Decibel API Key、API 钱包私钥、Trading Account、网络和目标模式；PAPER 页面不显示这些实盘连接设置。
- Telegram / Webhook 异常通知与自定义时间的每日盈亏日报。
- 脱敏审计日志、紧急停止和异常恢复流程。

## 模拟盘启动

### Windows

双击 `启动-模拟盘.bat`。

### macOS

双击 `启动-模拟盘.command`。首次若被系统阻止，可在终端执行：

```bash
chmod +x 启动-模拟盘.command
./启动-模拟盘.command
```

打开 `http://127.0.0.1:15000/paper`。模拟盘初始权益默认为 10,000 USDC，不会发送真实订单。

PAPER 页面可手动设置模拟账户权益，作为模拟入金或出金处理。该操作仅在网格已停止、恢复流程未运行、账户无持仓且机器人与交易所均无挂单时开放；调整后策略周期和当日盈亏都会以新权益重新建立零基线，资金变动不会被计为交易利润或亏损。LIVE 页面不提供此入口。

页面顶部的“并行模拟盘”区域用于新建和切换模拟账户。每个实例卡片持续显示实际运行状态、策略、权益和总盈亏；运行中的策略选择会锁定为真实策略，不会因状态刷新跳回列表第一项。删除实例前必须先停止、平仓并撤销所有挂单。大周期自动轮动目前只允许主模拟盘使用，其他实例可并行运行`区间平衡`、`顺势多头`或`顺势空头`。

## 页面入口

- `/paper` 是模拟盘工作台，使用明亮的白/绿配色，显示模拟盘就绪检查，不显示任何 Decibel 实盘连接、API 钱包、网络、代理或重启设置。
- `/live` 是实盘交易台，使用石墨黑/红色警示配色，集中显示实盘凭据、风控上限和实盘预检。
- 根地址会根据服务实际运行模式进入对应页面。页面模式与服务实际模式不一致时，页面保持只读并锁定交易动作，同时隐藏另一模式的账户、仓位、挂单、盈亏和运行记录，只显示该模式服务尚未启动。
- 公网部署对应入口为 `/deepBTC/paper` 和 `/deepBTC/live`。

页面顶部连接状态优先反映 SSE 实时流；SSE 暂时不可用但状态 API 正常时显示“轮询正常”。从页面执行“重启模拟盘”会重建实时流，不影响已经持久化的空闲账户状态。

## 配置个人版本

先复制配置文件：

```bash
cp .env.example .env
```

可先修改名称和模拟余额：

```ini
APP_NAME=GridPilot
OWNER_NAME=你的名字
PAPER_BALANCE=10000
```

模拟盘如需 Decibel 真实行情，前往 [Geomi](https://geomi.dev/) 申请并填写 API Key：

```ini
TRADING_MODE=paper
DECIBEL_API_KEY=你的_API_Key
```

## BTC 回测

运行 `npm run backtest:btc` 获取 Coinbase BTC-USD 1h 数据并执行默认 180 天回测。回测严格按时间顺序运行：趋势信号和新挂单只读取上一根已完成 K 线，当前 K 线只撮合此前已存在的订单。保护暂停的订单只有在条件解除且仍位于当前价被动一侧时才恢复，避免把已经穿价的旧订单当作正常限价单追价成交。

先运行 `npm run fetch:funding` 下载 BTC 永续合约真实历史资金费率，再运行 `npm run backtest:turtle` 执行独立的长期做多海龟研究回测。主体数据来自 Binance USD-M BTCUSDT 公共月度归档，尚未归档的最近月份由 OKX BTC-USDT-SWAP 已实现费率补齐；相同结算点优先采用 Binance。回测要求资金费率覆盖率至少 `95%`，不会在数据缺失时静默改用固定费率。

当前 PAPER 海龟规则为已完成日线的 20 日 Donchian 突破入场、10 日低点退出、20 日 Wilder ATR、`2N` 止损、每 `0.5N` 加仓和最多 4 个单位；每单位按 `2N` 止损约风险权益 `1.5%` 定量，总名义金额不超过权益 `100%`。15m K 线模拟突破和跳空成交，报告计入每次成交 `0.05%` 手续费、`2 bps` 滑点、`1 bp` 点差、逐期历史资金费率和期末强制平仓，并输出零成本、正常成本、双倍成本、固定 `0.01%/8h` 资金费率压力对照、逐年结果和持有基准。

`2021-09-01` 至 `2026-08-31` 的五年回测使用 `20/10 + 1.5%` 当前 PAPER 参数，真实资金费率覆盖 `5,464 / 5,475` 个结算点（`99.8%`）。初始 `10,000 USDC`，扣除全部成本后为 `+11,640.26 USDC / +116.40%`，最大回撤 `29.57%`，44 笔完整交易、胜率 `25%`、市场暴露 `35.98%`。手续费、滑点、点差和资金费率分别为 `404.98`、`161.99`、`81.00`、`2,172.64 USDC`；双倍全部成本为 `+7,868.48 USDC / +78.68%`。2022 年独立窗口亏损 `19.56%`，说明提高入场频率和单位风险会显著放大熊市回撤；该策略仅接入 PAPER，LIVE 仍不可用。

运行 `npm run backtest:ai-rotation` 可执行默认 1095 天的大周期自动轮动回测。脚本分段读取并缓存 Coinbase BTC-USD 15m 数据，只用完整且已经收盘的数据聚合 1H、4H 和 1D 周期，并复现默认每 `60` 分钟分析、连续 `12` 小时全票一致确认、`2880` 分钟最短持有、震荡中性网格、小时参数更新和完整执行成本。执行方向完全来自可审计规则；可选大模型只补充文字解释，不修改交易目标。

`2023-08-28` 至 `2026-08-27` 的 3 年绩效窗口使用 `113,703` 根含指标预热的 15m K 线。当前 PAPER 默认大周期策略为 `+767.04 USDC / +7.67%`，最大回撤 `3.66%`，成本前 `+1,062.69 USDC`、执行成本 `295.65 USDC`、直接策略切换 18 次，市场暴露 `85.17%`。三个独立年度分别为 `+270.76`、`+211.11`、`+142.50 USDC`；零成本为 `+936.42 USDC`，双倍成本为 `+467.82 USDC`。这些是历史规则回放，不是收益承诺，尤其做空子策略在完整窗口仍为负贡献。

候选优化必须先运行 `npm run backtest:ai-rotation:train`，只使用前两年和其中的半年滚动窗口；参数冻结后再运行 `npm run backtest:ai-rotation:validate`，只比较冻结候选与旧基线的最后一年。当前研究候选加入低波动震荡暂停、严格做空、做空失效提前退出、做空 2% 保证金和中性 0.8% 最小格距：训练段从 `+616.92` 提高到 `+1,053.54 USDC`，但冻结样本外仅 `+34.17 USDC`，低于基线 `+142.50 USDC`，因此没有写入 PAPER 默认策略。其样本外最大回撤从 `2.12%` 降至 `0.21%`，可保留为低回撤研究方向，但不能描述为收益优化已经成立。

运行 `npm run backtest:ai-rotation:v3` 可比较基线、空仓型 V2 和保持型 V3。V3 沿用冻结门槛，但在新市场类型尚未完成连续确认时保持当前策略，不因低波动或弱趋势主动空仓；只有剧烈波动安全信号和原有区间外止损可以暂停。三年回溯中 V3 为 `+1,097.57 USDC / +10.98%`、最大回撤 `3.59%`、市场暴露 `78.72%`，做空净贡献由基线 `-221.39` 改善为 `-16.04 USDC`。三个年度为 `+494.77`、`+407.31`、`+51.10 USDC`，最近一年仍低于基线 `+143.43 USDC`。由于 V3 是在查看上一轮验证结果后提出，该结果不是新的样本外证据，尚未写入 PAPER 默认策略。

运行 `npm run backtest:ai-rotation:robustness` 可执行固定的 5 年稳健性研究，比较生产基线、V3、V3 禁止做空，以及把 V3 现有做空单格数量再减半的候选。报告使用 18 个月训练、随后 6 个月验证并每 6 个月前移的 7 个滚动折，同时输出 `1x/2x/3x` 成本和 10 个单参数扰动。固定使用“V3 做空再减半”在滚动验证折中累计 `+717.19 USDC`，但 5 年最差半年为 `-484.47 USDC`、三倍成本为 `-346.09 USDC`，且 10 个扰动中 2 个转负；所有候选均未通过晋级门槛，因此 PAPER 默认策略没有改变。新增的较早历史属于提出 V3 后才查看的历史挑战集，不是真正的未来样本。

可用环境变量做敏感性实验：`BACKTEST_DAYS`、`BACKTEST_FEE_RATE`、`BACKTEST_SLIPPAGE_BPS`、`BACKTEST_SPREAD_BPS`、`BACKTEST_FUNDING_8H_RATE`、`BACKTEST_MAX_DIRECTIONAL_NOTIONAL_PCT`、`BACKTEST_GRID_SIZE_MULTIPLIER`、`BACKTEST_GRID_COUNT_MULTIPLIER`、`BACKTEST_TREND_SLOPE_THRESHOLD`、`BACKTEST_TREND_GUARD_MIN_STRENGTH` 和 `BACKTEST_TREND_CONFIRM_BARS`。`BACKTEST_FLATTEN_ADVERSE_TREND=true` 与 `BACKTEST_REGIME_MODE_SWITCH=true` 是研究开关，不会改变正在运行的 PAPER/LIVE 策略。

1h 数据无法可靠模拟 `750ms` 成交延迟和随机部分成交。回测结果用于成本敏感性、参数排除和不同时间窗口对照，不作为盈利或上线承诺。

## 实盘配置

准备以下信息：

1. 在 [Geomi](https://geomi.dev/) 申请 Geomi API Key。
2. 在 [Decibel 应用](https://app.decibel.trade/) 创建 API 钱包；使用 API 钱包私钥，不要使用主钱包助记词或主钱包私钥。
3. 在 [Decibel 应用](https://app.decibel.trade/) 账户页获取 Trading Account 地址。
4. 已存入交易保证金的 Decibel 账户。
5. API 钱包地址中准备少量 APT，用于支付链上挂单、撤单和设置杠杆的 Gas。

在 `.env` 中填写：

```ini
TRADING_MODE=live
ENABLE_LIVE_TRADING=true
LIVE_CONFIRMATION=I_ACCEPT_DECIBEL_LIVE_RISK
DECIBEL_NETWORK=mainnet
DECIBEL_API_KEY=
DECIBEL_PRIVATE_KEY=
DECIBEL_SUBACCOUNT=
DECIBEL_ORIGIN=http://127.0.0.1
```

服务启动时会检查这些字段。缺少任意一项都会直接拒绝进入实盘模式。

也可以在 `/live` 操作台的“Decibel 连接”面板填写 API Key、API 钱包私钥、Trading Account、网络和重启后的目标模式。敏感内容不会回显，保存后写入本机 `.connection-settings.json`，重启服务后生效。选择实盘时必须输入 `ENABLE DECIBEL LIVE`。该面板不会出现在 `/paper`。

同一面板可以配置 Decibel 专用 HTTP(S) 或 SOCKS5 代理。代理账号与密码不会回显，保存后随模拟盘重启生效。

模拟盘使用真实行情时，页面会显示实际数据网络（Mainnet 或 Testnet）。配置目标网络与实际数据网络不一致时，实盘预检会阻断启动。

### 实盘启动

Windows 双击 `启动-实盘.bat`，macOS 双击 `启动-实盘.command`。命令行要求再次输入 `DECIBEL`，随后页面仍需完成实盘预检和逐市场确认。

服务进入实盘模式后访问 `http://127.0.0.1:15000/live`。仅打开实盘页面不会切换服务模式，也不会启用真实下单。

正常启动网格时输入：

```text
LIVE BTC-USD
```

若该市场已有仓位，普通启动会被拒绝。使用“重新建网格”接管时输入：

```text
REGRID BTC-USD
```

市场名称以页面实际显示为准。

## 实盘预检

点击“实盘预检”，系统检查：

- 实盘模式和总闸门。
- API Key、API 钱包私钥和 Trading Account 格式。
- Decibel 连接、市场列表、实时价格和账户权益。
- API 钱包的 APT Gas 余额。
- 配置目标网络与实际数据网络是否一致。
- 现有挂单、现有仓位和日内风险锁。
- Telegram / Webhook 是否配置。

预检通过后有效 5 分钟。每次成功启动实盘网格后，预检结果立即作废，下一次启动必须重新检查。

## 风控参数

默认实盘上限：

| 配置 | 默认值 | 含义 |
|---|---:|---|
| `LIVE_MAX_LEVERAGE` | `10` | 最大杠杆；交易所市场上限仍优先 |
| `LIVE_MAX_GRID_COUNT` | `0` | 最大格数；`0` 表示交给保证金/维持保证金率动态限制 |
| `LIVE_MAX_NOTIONAL` | `0` | 最大名义价值，USDC；`0` 表示不单独限制 |
| `LIVE_MAX_MARGIN_PCT` | `35` | 预估保证金占账户权益上限 |
| `LIVE_MIN_MAINTENANCE_RATIO` | `300` | 预计维持保证金率下限；低于该值拒绝实盘启动 |
| `LIVE_DAILY_LOSS_LIMIT` | `20` | UTC 日内最大权益损失，USDC |
| `LIVE_MAX_DRAWDOWN_PCT` | `30` | 当日权益高点最大回撤百分比 |

这些值可以在 `.env` 中自由修改，可根据账户权益、交易品种和策略规模设置。

风险锁记录在 `.risk-state.json`。达到日内亏损或回撤阈值后会锁定新启动，并在网格运行时触发紧急停止。停止后必须人工核对交易所，再输入 `RESET RISK` 重置基线。

## 命名策略与自动参数

启动面板只提供以下策略选择：

| 策略 | 方向 | 适用范围 |
|---|---|---|
| 区间平衡 | 中性 | 震荡行情，现价两侧同时布置网格 |
| 顺势多头 | 做多 | 已确认的上涨趋势 |
| 顺势空头 | 做空 | 已确认的下跌趋势 |
| 大周期自动轮动 | 自动 | PAPER 专用，按 1D/4H/1H 大周期运行做多、做空或中性网格 |
| V3 保持型轮动（试验） | 自动 | PAPER 专用，门槛不足时保持当前策略，过滤弱下跌和低波动中性网格 |
| Grok 情绪增强轮动（试验） | 自动 | 主 PAPER 专用，大周期定方向，X/网页情绪只做确认、阻断和风险暂停 |
| 海龟突破做多 | 做多 | PAPER 专用，20 日突破、10 日退出和 ATR 风险单位 |

浏览器只向 `/api/strategy-start` 提交策略 ID 和市场 ID。服务端会读取最新 BTC 价格、`ATR(1h)`、账户权益、仓位和市场精度，在预览时生成一次参数，并在启动前再次重新生成和风控。页面不允许编辑以下具体数值：

| 参数 | 含义 |
|---|---|
| 中性 | 现价下方挂买单、上方挂卖单 |
| 做多 | 下方开多，成交后在上一格挂只减仓卖单 |
| 做空 | 上方开空，成交后在下一格挂只减仓买单 |
| 下/上边界 | 网格运行价格范围 |
| 网格数量 | 区间分格数量 |
| 每格数量 | 每张订单的基础币数量 |
| 杠杆 | 影响保证金占用和强平风险 |
| 撤单并平仓 | 价格出区间后停止并尝试平仓 |
| 只减仓回收 | 价格出区间后只挂减少现有仓位的退出单 |
| 最大方向敞口 | 单边净持仓名义价值占权益的上限，默认 `15%` |
| 趋势保护 | 强趋势中暂停逆势新增仓位，默认开启 |

中性网格适合震荡行情，会在上涨过程中逐格卖出，因此在持续单边上涨中仍可能积累空头。未选择大周期自动轮动时，确认上涨趋势已经形成后应选择“顺势多头”；如果区间平衡已经运行，先停止并处理已有空头，再选择顺势多头。趋势保护不会把静态策略自动切换成另一方向。

自动参数默认使用 `2x` 杠杆、`6%-18%` 区间半宽、`10-40` 格和至少 `0.6%` 的目标格距。目标保证金按周期分配：做多约占权益 `8%`，中性和做空约占 `4%`；区间外动作为撤单并平仓。用户不再修改或保留旧数值；每次启动都以服务端最新计算为准。

模拟盘默认开启小时参数引擎：网格运行时每 `60` 分钟重算边界、格数、每格数量和杠杆。价格进入区间边缘且边界变化达到 `10%`，或格数/单格数量变化达到 `20%`，才撤销旧单并重建；成功后冷却 `240` 分钟，持仓和策略方向保持不变。实盘默认关闭自动参数更新。每次更新都重新执行市场、最小下单量、保证金与风险检查。

方向敞口按 `abs(净持仓数量 × 最新价) / 账户权益` 计算。达到上限时不会强制平仓，只会停止继续增加该方向；反向退出单会使用 `reduceOnly`。趋势保护不会把中性网格切换成做多或做空模式，只会临时暂停危险的开仓方向，趋势恢复后再恢复仍有效的挂单。

模拟盘默认执行成本为：单边手续费 `0.05%`、滑点 `2 bps`、点差 `1 bp`、每 8 小时资金费率 `0.01%`、成交确认延迟 `750ms`、部分成交概率 `35%`（单次成交剩余量的 `50%`）。这些值可通过 `.env` 中的 `PAPER_*` 参数调整。正资金费率表示多头支付、空头收取；页面“PAPER 执行损耗”按当前统计周期显示手续费、滑点、点差和资金费率拆分。

每次成功启动网格、人工/自动调区间、人工重置统计或调整 PAPER 账户权益，都会开始新的参数统计周期。本周期已实现、未实现变化、总盈亏、成交量、完成格数和执行成本均从当时状态重新建立基线；最近 12 个已结束周期随快照保存，用于比较不同参数。普通统计重置不会改变账户总权益，PAPER 权益调整则会把资金变动与策略收益分开记录。

实盘启动时服务器会计算完整名义价值、预估保证金和预计维持保证金率，不会绕过交易所市场上限或项目实盘风控；请先在模拟盘观察，再按账户规模调整参数并重新完成预检。

## 遗留仓位处理

检测到有仓位但网格未运行时，页面提供三种操作：

- **重新建网格**：保留仓位并按当前参数重新挂网格。实盘需输入 `REGRID 市场名`，已有仓位名义价值会计入风控上限。
- **只减仓回收**：只挂减少仓位的退出阶梯，不新增方向仓位。实盘需输入 `RECOVER 市场名`。
- **立即平仓**：撤销该市场普通挂单并发送 reduce-only IOC 平仓单。实盘需输入 `CLOSE 市场名`。

撤单或平仓执行后，可在 Decibel 网页端核对最终订单和仓位状态。极端行情、网络中断或链上交易失败时，以链上实际结果为准。

## 紧急停止与退出

“紧急停止”要求输入 `EMERGENCY STOP`，随后撤销挂单并最多重试三次平仓。

直接关闭程序时，系统会写入审计并发送通知，但**不会擅自自动撤单或平仓**。这是为了避免关机、网络异常或重复信号导致额外交易。进程退出后，Decibel 上的订单和仓位可能继续存在，必须人工核对。

## 通知

操作台的“每日盈亏通知”面板可直接填写：

- Telegram Bot Token。
- TG ID / Chat ID。
- 每日发送时间。
- 统计时区。
- 是否开启每日推送。

Token 不会通过接口回显，保存于本机 `.notification-settings.json`。日报以所选时区当天首次记录到的账户权益作为日初基线，内容包含当日盈亏、收益率、账户权益、已实现/未实现盈亏、仓位和挂单数量。支持“测试通知”和“立即发送日报”。

Telegram Bot API 使用 `sendMessage` 向配置的 `chat_id` 发送文本。也可继续通过 `.env` 配置：

Telegram：

```ini
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=
```

通用 JSON Webhook：

```ini
NOTIFY_WEBHOOK=https://你的地址
```

通知失败只会记录审计，不会阻断撤单和平仓流程。定时日报失败后会间隔 10 分钟重试，同一日期和计划时间成功发送后不会重复推送。

## AI 助手

操作台的“AI 助手”面板支持 OpenAI 兼容接口、xAI/Grok、Anthropic 和 Gemini。配置 API Key、Base URL 与模型后，可以：

- 基于 1 天、4 小时和 1 小时已完成 K 线解释当前大周期。
- 大周期执行方向由确定性规则产生；配置大模型后只补充文字分析和风险提示。
- 根据实时权益、持仓、挂单、盈亏和风险状态回答问题。
- 定时运行风控巡检和 BTC 市况分析，并在指定小时生成 AI 复盘。
- 价格首次冲出区间时生成处置建议并通过已配置的通知渠道推送。
- 对话可以提出填参、调区间、重连、撤单或停止建议，但必须由用户再次确认。
- PAPER 页面可选择`大周期自动轮动`。启用时先按每个历史决策点当时已经收盘的数据回放最近 `12` 个小时，若已连续满足门槛就立即挂模拟单；若只满足末尾若干次，则从该次数继续确认。之后默认每 `60` 分钟分析一次，同一根已完成 1H K 线不会重复计数；1D/4H/1H 必须连续 `12` 小时全票一致，才允许启动或切换对应的中性、做多、做空网格。实际动作后至少保持 `2880` 分钟。信号暂时不一致时保持当前策略，只有剧烈波动安全信号才进入暂停。该策略仍默认关闭，必须人工选择并确认启用。
- 主 PAPER 可选择`Grok 情绪增强轮动（试验）`。启动后立即分别搜索最近 24 小时的 X 和网页公开信息，再单独合并两份摘要；原生 xAI 并行搜索，受并发额度限制的兼容代理使用受控串行。之后每 `15` 分钟分析一次，任一渠道失败时本轮保持现状。至少需要 `3` 个独立引用来源、`65%` 置信度、净情绪分数达到 `±0.15`，并连续确认 `2` 次。成功动作后冷却 `360` 分钟。普通反向情绪只保持当前策略；高可信反向重大事件只形成连续风险暂停候选，不直接切换为相反方向。

普通 AI 分析和聊天只提供建议，不会执行交易。人工选择 PAPER 大周期自动轮动后，确定性状态机负责市场分类和方向，区间、格数、每格数量、杠杆和保护参数由最新 BTC `ATR(1h)`、权益、仓位与市场精度完整重算。多周期不一致时保持现状；切换前必须通过风控，并确认旧挂单撤销和原仓位平仓。该自动策略不要求配置 AI API Key。

大周期自动策略不保证盈利，周期指标存在滞后，切换和平仓可能把浮亏转为已实现亏损。该能力仅允许 PAPER 模拟盘，LIVE 实盘始终拒绝自动切向。可选 API Key 保存在本机 `.ai-settings.json`，公开接口只返回是否已配置，不会回显密钥。

Grok 情绪策略目前没有可复现的历史 X/网页语料回测，只允许 PAPER 前向观察。缺少 xAI Key、Provider 不为 xAI、搜索失败、引用不足或报告过期时，运行中的网格保持现状，尚未入场时继续等待。情绪报告、引用和决策会写入审计，API Key 不会写入审计或 Git。

若要停止全部自动 AI 调用，将巡检间隔和市况间隔设为 `0`、日报小时设为 `-1`，并关闭自动轮动。该设置仍保留人工连接测试和人工情绪分析入口。Grok 情绪报告只认可 Responses 接口返回的引用元数据；模型正文里的 URL 不能替代引用校验。

也可以通过 `.env` 配置：

```ini
AI_PROVIDER=openai
AI_API_KEY=
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=gpt-5.6-terra
AI_MODEL_SMALL=gpt-5.6-terra
AI_SENTINEL_MINUTES=5
AI_MARKET_MINUTES=60
AI_REPORT_HOUR=20
AI_AUTOPILOT=false
AI_AUTOPILOT_MIN_CONFIDENCE=0.8
AI_AUTOPILOT_CONFIRMATIONS=12
AI_AUTOPILOT_COOLDOWN_MINUTES=2880
AI_AUTOPILOT_MIN_TIMEFRAME_VOTES=3
AI_AUTOPILOT_NEUTRAL_AS_PAUSE=false
```

使用 Grok 情绪策略时在页面选择 `xAI / Grok` 即可自动填入 `https://api.x.ai/v1` 和 `grok-4.6`；填入 xAI API Key 并测试连接后再选择策略。策略启动会把市况间隔、确认次数和冷却固定为上述 PAPER 试验值，避免页面旧值改变策略定义。

## 状态和审计文件

- `.state.json`：网格运行快照，不保存私钥。
- `.risk-state.json`：UTC 日内风险基线和锁定状态。
- `.audit.jsonl`：脱敏操作记录，达到约 5 MB 后轮换为 `.audit.jsonl.1`。
- `.connection-settings.json`：面板保存的 Decibel 连接凭据和目标模式，权限限制为当前用户。
- `.notification-settings.json`：Telegram 与日报时间设置，权限限制为当前用户。
- `.ai-settings.json`：AI 提供商、模型与 API Key，权限限制为当前用户。
- `.ai-autopilot.json`：大周期自动轮动的候选方向、连续确认、最短持有和最近动作状态。
- `.paper-instances.json`：PAPER 实例名称、所选策略和各自小时参数状态；各实例交易快照保存在 `.state.json` 的独立键中。
- `.daily-pnl.json`：所选时区的日初权益、最新权益和最后发送记录。

这些运行文件已加入 `.gitignore`，打包交付时也应删除。

## 部署建议

1. 先运行模拟盘，确认行情、网格、补单、调区间和通知功能正常。
2. 根据账户规模配置杠杆、保证金占比、维持保证金率和回撤上限；网格数与名义金额上限可设为 `0`，交给动态风险计算。
3. 实盘首次启动选择合适的命名策略，并在 Decibel 页面同步核对自动参数、订单与仓位。
4. 测试撤单、重启恢复、遗留仓位处理和紧急停止流程。
5. 稳定运行后再逐步调整风险上限和观察周期。
